# 待办怎么理

待办清单失败的方式只有一种：**看起来很长，但没有一条知道下一步该干什么**。

## 步骤

1. **四处都扫**：`calendar_list`（今天和接下来几天）、`memory_list`、用户指定的笔记目录（`glob` + `grep` 找 `- [ ]`）、本轮对话里口头提过的事。漏一处就在输出里写明"没扫哪一处"。
2. **每条补齐三件**：做什么（动词开头，能一手完成）、什么时候前（原文没有的写「未定」）、出自哪里（哪个文件哪一行 / 哪次日程 / 谁说的）。
   - 写不出"做什么"的条目，是**项目不是任务**：「搞定报销」要拆成「把 3 月发票拍照存进 folder 并填提交表」。拆不动就问用户一句。
3. **分四类**：今天必做 / 有过期风险的 / 只有你能做的（等别人、需要你的账号或决定）/ 可以我代做的。
   - 第四类要具体说清我能做到哪一步、卡在哪一步需要你。
4. **过期判定**：以当前日期为准，明确写出「已过期 N 天」。过期不是错误，是信息 —— 但别用「逾期已久」这种不含数量的说法。
5. **落盘**：`write` 成 `待办-<日期>.md`，勾选框格式，方便下次 `grep` 出未完成项做增量。

## 不做的事

- 不 `memory_forget`：清单里"已完成"的东西可能还是用户想留的记录；
- 不新建日程，除非用户说了具体时间 —— 时间没定就挂在清单上；
- 不把同一件事按来源数算成多条：合并成一条，来源并列写全。

## 忌词

「跟进一下」「关注」「看看情况」—— 这些是**没有下一步**的委婉说法，出现就说明还没拆到位。
