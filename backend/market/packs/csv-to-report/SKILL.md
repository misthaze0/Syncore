# 脏表怎么并

表格合并出错的代价是**数字看起来对**。所以流程的重点在核对，不在合并。

## 步骤

1. **先盘点**：`glob` 找出所有待并文件，逐个读表头，列一张对照表：文件 / 行数 / 有哪些列 / 日期格式 / 金额单位。**没盘点就动手合并的，最后一定有一列是空的**。
2. **口径先定后算**，写进输出的说明页：
   - 金额单位（元/万元）、是否含税；
   - 日期取哪个（发生日 vs 入账日）、跨月怎么归；
   - 同名不同义（A 表的"部门"是成本中心，B 表是行政归属）；
   - 重复行以哪个文件为准，规则是什么。
   任何一条定不了，**停下来问**，不要选一个默认值继续。
3. **清洗规则要能复述**：去空行、去重（按哪几列判重）、类型转换（哪些列转数字、哪些保持文本）、缺失怎么处理（填 0 / 留空 / 剔除整行，三选一必须写明）。
4. **合并后必做的三道核对**：
   - 总行数 = 各文件有效行数之和 − 去重条数，对不上就说清差在哪；
   - 关键数值列的合计，逐文件各算一遍再相加，和合并表的结果比；
   - 随机抽 3 行回到原文件核对。
   核对结果写进输出，不写"已核对无误"这种自证。
5. **产出**：`generate_document` 出 xlsx，含 明细 / 汇总 / 说明（口径 + 清洗规则 + 核对结果）三个 sheet。

## 红线

- 不改原始文件；
- 不为了"表好看"删掉异常值 —— 异常值单独列一张表交出去；
- 汇总数与原表不一致时，先报告不一致，再报告数字。

## 忌词

「基本一致」「大致准确」—— 表格要么对得上要么对不上，说清差多少。
