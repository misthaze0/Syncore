# 周报自查清单（落笔前过一遍）

## 取材

- [ ] 每条"本周完成"都能指回一个来源（一段对话、一份文档、一个后台任务的结果）
- [ ] 没有把"下周计划"混写进"本周完成"
- [ ] 数字来自材料原文，不是估的（估的要写"约"）
- [ ] 外部信息（联网查的）标了来源，不和用户自己的材料混在一条里

## 结构

- [ ] 四段：本周完成 / 进行中 / 下周计划 / 需要协调（空段已删）
- [ ] 每段 ≤ 5 条，一条一行，动词开头
- [ ] 全文 300–600 字
- [ ] "需要协调"里写清了**找谁、要什么、什么时候要**（只写"需要支持"等于没写）

## 语言

- [ ] 没有：赋能、抓齐、闭环、常态化、全面提升、在……的指导下
- [ ] 没有为了凑数而写的程度副词（"显著""大幅"后面必须跟数字，否则删掉）
- [ ] 项目/系统名用用户自己的叫法，不是我们的内部叫法

## 交付

- [ ] 文件名带日期
- [ ] 回复里说了文件路径
- [ ] 对话里只留三段以内的摘要，没有把全文再抄一遍
- [ ] 如果这周有明显没做完的事，写的是"进行中"而不是含糊过去
